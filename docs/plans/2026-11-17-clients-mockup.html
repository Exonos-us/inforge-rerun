Clients — UI mockup

A client is a workspace entity carrying skills, knowledge docs, a default Confluence space and a short code. A Box points at one; every coworker hired into that Box inherits it.

1 · Settings → Clients

A searchable table, built on the Table primitive from @rerun/ui/primitives, inside a PanelDialogContent. Search is the house pattern — a SearchIcon inset in an Input, as in OpencodeModels.tsx:84. The header row is sticky, so it survives scrolling a long list.

6 · On the coworker itself

In the coworker's Skills tab, the client's skills read as inherited and are not editable there — editing one would silently diverge from the client, which is the drift you wanted to avoid. The way to change it is a link straight to the client.
